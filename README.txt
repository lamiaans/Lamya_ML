Dataset Description

This dataset contains makeup product reviews. It includes information such as ratings, helpful votes, review text, and dates.

The goal of this analysis is to explore user behavior and understand patterns in ratings and reviews.

The dataset was cleaned by handling missing values and converting data types such as dates and ratings.

EDA techniques were applied, including:
- Univariate analysis (distribution of ratings and helpful votes)
- Bivariate analysis (relationships between variables)
- Time-based analysis (reviews over time)

The analysis shows that most ratings are high, helpful votes vary depending on review details, and user activity has increased over time.
